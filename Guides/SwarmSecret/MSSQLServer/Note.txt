1. Pull Microsoft SQL Server image dari microsoft, kita akan menggunakan versi 2022
docker pull mcr.microsoft.com/mssql/server:2022-latest

2. Buat volume untuk persistent database:
docker volume create sqlserver_volume

3. Check volume:
docker volume ls

======================== SECRET ==============================

4. Buat password secret:
docker secret create mssql_sa_password mssql_sa_password.txt

5. Check eksistensi kedua secret:
docker secret ls

======================== UPGRADE IMAGE ==============================

6. Upgrade image dengan docker file, supaya ditambahkan entrypoint.sh sejak awal:
docker build -t sqlserver-secret:1.0 .

7. Pastikan image yang baru sudah ada:
docker images

======================== DEPLOY ==============================

8. Lalu deploy stack dengan:
docker stack deploy -c docker-stack.yaml sqlstack

============================== SSMS ====================================

7.a. Test dengan akses SSMS dengan menggunakan detail di bawah ini:
server name: localhost,1433
username: sa
password: SmithWessonMagnum357!
encryption: Trust Certificate
