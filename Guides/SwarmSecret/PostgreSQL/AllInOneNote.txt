1. Pull PostgreSQL image dari dockerhub, kita akan menggunakan versi 17.10
docker pull postgres:17.10

2. Buat volume untuk persistent database:
docker volume create postgres_volume

3. Check volume:
docker volume ls

4. Pastikan tidak ada secret yang berhubungan dengan project ini.

======================== DEPLOY ==============================

5. Deploye external_secret.yaml dengan:
docker stack deploy -c all_in_one.yaml -d my_project
