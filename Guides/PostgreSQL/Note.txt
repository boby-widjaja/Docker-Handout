1. Pull PostgreSQL image dari dockerhub, kita akan menggunakan versi 17.10
docker pull postgres:17.10

2. Buat volume untuk persistent database:
docker volume create postgres_volume

3. Check volume:
docker volume ls

======================== RUN ==============================

4a.1. Cara buat container dengan run command:
docker run -d \
  --name postgres_container \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=nodecomplete \
  -e POSTGRES_DB=mystore \
  -p 5432:5432 \
  -v postgres_volume:/var/lib/postgresql/data \
  postgres:17.10

======================== DOCKERFILE ==============================

4b.1. Cara buat container dengan Dockerfile, change directory ke PostgreSQL
cd Guides/PostgreSQL

4b.2. Build PostgreSQL image
docker build -t postgres-private:1.0 .

4b.3. Run image yang sudah dibuat
docker run -d \
    --name postgres_container \
    -p 5432:5432 \
    -v postgres_volume:/var/lib/postgresql/data \
    postgres-private:1.0

============================== PgAdmin dan backup file ====================================

5a.1. Membuat Connection ke database
Servers > Click Kanan > Register > Server
General Tab
    Name: Container
Connection Tab
    Host name/address: localhost
    Port: 5432
    Username: postgres
    Password: nodecomplete

5a.2. Membuat database
Databases > Klik Kanan > Create > Database
Berikan nama mystore, lalu save 

5a.3. Me-restore database
Pertama pastikan tidak ada public di dalam schema dengan menghapusnya.
mystore > klik kanan > restore > General > File Name > brows backup file > Restore.

============================== DBeaver ====================================

5b.1. Buat connection
New Database Connection > PostgreSQL
Host: localhost
Port: 5432
Username: postgres
Password: nodecomplete

5b.2. Restore database:
Open File > mystore.sql

5b.3. Apabila connection belum terhubung ke database:
Ctrl + 9
Lalu pilih koneksi

5b.4. Execute Script:
Execute SQL Script (Alt + X)

=====================================================================

6. Masuk ke container dengan bash:
docker exec -it postgres_container psql -U postgres

7. Kalau setelah execute container hasilnya:
postgres=#
Berarti sudah masuk ke postgres.

8. Check version dengan:
SELECT version();

9. Kita bisa check seluruh database kita dengan:
\list

10. Untuk connect ke database yang kita mau:
\connect mystore

11. Untuk lihat semua schema dan table:
\dt

12. Untuk check structure table:
\d products

13. Coba untuk select data products:
SELECT * FROM products;

14. Keluar dengan:
\q
