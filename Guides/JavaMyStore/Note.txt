1. Di sini kita akan menggunakan postgreSQL sebagai DBMSnya, pastikan kita sudah memiliki
image postgres dengan versi yang tepat dengan:
docker images

Kalau belum ada silahkan di pull terlebih dahulu:
docker pull postgres:17.10

2. Jalankan container dengan: (tidak perlu host port dan tidak perlu volume dulu untuk percobaan ini)
docker run -d \
  --name postgres_container \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=nodecomplete \
  -e POSTGRES_DB=mystore \
  postgres:17.10

3. Execute bash dan masuk ke dalam container databasenya:
docker exec -it -u root postgres_container bash

4. Untuk memastikan postgres siap, bisa gunakan:
pg_isready

Tanda postgres ready adalah dengan adanya feedback: accepting connections.

5. Masuk ke postgres dengan user postgres:
psql -U postgres

Kalau berhasil masuk prompt akan menjadi seperti ini:
postgres=#
Dimana ini artinya kita berada di dalam postgres dan bisa langsung ketik sql command.

6. Bila belum ada database mystore, buat dulu dengan command DDL ini:
CREATE DATABASE mystore;

7. Check apakah databasenya berhasil dibuat dengan command ini:
\list

8. Connect ke database mystore dengan:
\c mystore

9. Buat table products dengan script DDL ini:
CREATE TABLE products
(
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    stock INTEGER NOT NULL,
    price NUMERIC(15,2) NOT NULL,
    description VARCHAR(500)
);

11. Kalau sudah selesai kita bisa keluar dari postgres CLI app dengan:
\q

12. Lalu exit dari bash dengan:
exit

13. Create network baru yang akan menghubungkan app dengan databasenya:
docker network create mystore_network

14. Hubungkan database container dengan network:
docker network connect mystore_network postgres_container

15. Build image java app mystore-nya:
docker build -t java-mystore:1.0 -f Dockerfile.runner .
atau kalau mau menggunakan multi-stage yang dibuild dari source code:
docker build -t java-mystore:1.0 -f Dockerfile.builder .
atau bisa juga menggunakan:
docker build -t java-mystore:1.0 -f Dockerfile.optimized .

16. Buat container java app dari image di langkah sebelumnya:
docker container create -it --name mystore_cli java-mystore:1.0
bila menggunakan optimized:
docker container create -it \
  --name mystore_cli \
  -e DB_PASSWORD=nodecomplete \
  java-mystore:1.0

17. Hubungkan app dengan existing network yang dibuat di langkah sebelumnya:
docker network connect mystore_network mystore_cli

18. Jalankan containernya dengan attached processnya ke terminal dan lihatlah apakah data product keluar?
docker container start -ai mystore_cli
