Ping adalah command Networking yang digunakan untuk menguji jaringan ke sebuah host, apakah host tersebut
bisa dijangkau atau tidak. Ping bekerja dengan memantulkan atau mem-PING pong sebuah paket kecil
ke host yang dituju dan mengukur waktu paket tersebut terpantul balik.

Penggunaan ping secara general:
ping [hostdomain]
ping google.com
atau
ping 8.8.8.8

Ping secara default di Linux terjadi terus-terusan, untuk ping terjadi dalam hitungan yang ditentukan,
kita harus menggunakan operasi count, lalu argument angka bulat.
ping -c 4 google.com

Kalau kita tidak mau antar ping berlangsung terlalu cepat, kita harus menggunakan option interval.
ping -i 2 google.com

Pada dasarnya ping akan menunggu terus menerus sampai paket ping dalam waktu lama tidak kembali,
baru ping me-label kan tersebut sebagai RTO (Request Timeout). Tapi berapa lama menunggu sampai RTO juga bisa kita set 
dengan option Wait.
ping -c 1 -W 3 google.com

Kita juga bisa diatur ukuran size paketnya. 1000 byte lebih sedikit (Kurang lebih tambah 28 byte lagi untuk request header)
ping -s 1000 google.com

Apabila kita tidak mau melihat proses ping satu-persatu dan mau langsung lihat kesimpulan akhir, kita bisa tulis command quit.
ping -c 10 -q google.com

Pada kesimpulan, kalian bisa melihat informasi seperti di bawah ini:
rtt min/avg/max/mdev = 14.3/18.2/25.7/3.1 ms

Artinya:
min = latency minimum
avg = rata-rata
max = maksimum
mdev = variasi latency
