1. C-Matrix ===============================================================================================================

Di sini kita akan mencoba menjalankan sebuah program kecil yang bisa memunculkan animasi ala film matrix di dalam terminal.
Seluruh exercise beserta contoh dan catatannya bisa ditemukan di directory Guides/CMatrix.
Tujuan dari exercise ini adalah melihat sebuah proses aplikasi sederhana diatas linux container, dimana prosesnya bisa disederhanakan
dengan proses build yang lebih lengkap. Sample dari docker file perlahan berkembang dari Sample 1 ke Sample 5, dimana sample 5 adalah yang
paling lengkap.

Seandainya saja kita ingin menjalankan proses cmatrix ini, tentu langkah yang harus kita penuhi adalah:
1. Memastikan container berisi linux distro (dalam hal ini kita pakai fedora) harus berjalan.
2. Kita harus masuk ke dalam container yang sedang berjalan, lalu bisa meng-eksekusi bash command.
3. Kenapa kita ingin meng-eksekusi bash command? Karena kita ingin install app cmatrix yang kita download dari internet
dan proses instalasinya harus lewat bash command.
4. Kita jalankan cmatrix yang sudah terinstal tadi.

Seandainya kita ingin menjalankan ini semua tanpa membuat image baru yang lebih lengkap dengan dockerfile, sebenarnya
memungkinkan saja, tetapi kita lihat apa kendalanya dan bagaimana dockerfile bisa membantu membuat image yang lebih
lengkap.

Jika kita tidak mau membuat image baru, berarti kita harus langsung run container dari image asli fedora yang kita terima dari
repository:
docker run --name cmatrix-container fedora:44

Maka code ini akan memiliki masalah, yaitu:
Container akan segera stop, karena sifat dasar container fedora:44 dari dockerhub adalah bila tidak ada proses apapun
yang berjalan di dalam container ini, otomatis di stop saja.

Oleh karena itu kita harus memastikan kalau prosesnya tidak terhenti dengan menggunakan command:
tail -f (follow the tail of the file)
tail command bisa dibaca di Shell Notes bagian HeadTail-Outputprocessing, dimana kegunaannya adalah untuk terus memonitor
sebuah file atau sebuah log yang sedang di update di bagian bagian paling belakang.
Command tail -f kita akali sebagai trick untuk membuat container tidak ditutup otomatis, 
seolah-olah "Saya masih mengawasi dan memonitor sebuah file! Jangan ditutup dulu!"
Trick untuk membuat container terus berjalan tidak harus dengan menggunakan follow tail seperti ini, tetapi
ini adalah trick umum yang biasa dipakai banyak admin ketika belajar container pertama kali.

Kalau kita ingin memonitor sebuah file, tail -f akan meminta target file yang akan di follow dalam parameter
command. Kita akan targetkan dia ke dalam directory /dev/null.
/dev/null adalah special device yang tidak pernah memiliki data dan tidak pernah bertambah isinya.
Tail akan memonitor sebuah file yang tidak akan pernah berubah.

Kalau kita menulis seperti ini, container tidak akan berhenti.
docker run --name cmatrix-container fedora:44 tail -f /dev/null
Note: Kalau kalian menjalankan command seperti ini di gitbash tidak akan berjalan lancar, karena gitbash merubah penulisan path secara otomatis.
Jadi jalankan di Linux Bash/ Windows CMD/ Powershell.

Tapi proses ini juga akan bermasalah karena walaupun container jalan, kita akan dihadapkan dengan layar kosong yang
terus menerus memantai file kosong /dev/null. Kita akan detatched proses agar container bisa berjalan di background.
Dan satu lagi mungkin kita akan terus kerepotan untuk terus menerus menghapus container yang kita buat dari hasil experiment.
Supaya container bisa terhapus otomatis, kita juga akan memberikan option remove agar saat container di stop akan terhapus otomatis:
docker run -d --rm --name cmatrix-container fedora:44 tail -f /dev/null
